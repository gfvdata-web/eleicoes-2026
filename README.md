# Governadores 2026 — Pesquisas

Mapa interativo com as últimas pesquisas de intenção de voto para governador nas eleições de 2026 (1º turno em 04/10/2026), estado por estado.

**Site:** https://gfvdata-web.github.io/governadores-2026/

- Passe o mouse (ou toque) sobre um estado para ver as 3 pesquisas mais recentes.
- A tabela abaixo do mapa traz candidatos, partidos e um breve resumo de cada um, com filtro por estado e região.

Dados em [`docs/data/dados.js`](docs/data/dados.js). Fontes: Quaest, Datafolha, AtlasIntel, Paraná Pesquisas, Real Time Big Data e outros institutos, compilados de O Povo, Gazeta do Povo e Wikipédia. Malha dos estados: [click_that_hood](https://github.com/codeforamerica/click_that_hood) (simplificada).

Voto cruzado — Espírito Santo

O voto para presidente acompanha os votos para governador, Senado e deputados? 1º turno de 2026 (04/10), urna por urna. Cada candidato conta para o campo do seu partido (esquerda, centro ou direita). Onde o voto para presidente fica acima ou abaixo do que os outros cargos indicam, o eleitorado daquela urna dividiu o voto.

O que dá para saber

O voto é secreto: não existe dado de como cada eleitor combinou os seus votos. O Registro Digital do Voto (RDV) que o TSE publica para cada urna guarda os votos de cada cargo em listas separadas e em ordem de número, sem ligação entre os cargos.

Por isso a análise compara urnas (em média ~240 votantes cada): se uma urna deu 60% à esquerda para presidente e 40% para governador, pelo menos 20% dos eleitores dali votaram em campos diferentes nos dois cargos, mas não dá para saber quais.

Onde o voto mais se descola

Campos: . A divisão é aproximada, segue o uso comum na imprensa (a mesma da página de bancadas) e pode conter imprecisões.

Previsão: regressão linear ponderada pelo comparecimento, ajustada nas urnas do estado inteiro: o % do campo para presidente é estimado a partir do % do mesmo campo para governador, Senado, deputado federal e estadual. A diferença é o % real menos o previsto. Voto dividido mínimo (comparação com um cargo): parcela de eleitores que, com certeza, votou em campos diferentes nos dois cargos (metade da soma das diferenças entre os 3 campos). Núcleo mínimo: parcela que, com certeza, votou no campo escolhido nos dois cargos. Os dois são limites matemáticos, não estimativas, e não se aplicam ao Senado (2 votos por eleitor). Urnas com poucos votantes oscilam mais.

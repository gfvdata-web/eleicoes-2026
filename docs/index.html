Como funciona: URNAS APURADAS + URNAS DO 1º TURNO

Ponto de partida: os votos de cada município no 1º turno (4/10), contando só os dois finalistas. Conforme as urnas do 2º turno são apuradas, os votos reais de hoje substituem os do 1º turno, na proporção das urnas apuradas em cada município. Com 0% apurado, a previsão repete o 1º turno; com 100%, é o resultado oficial. É uma conta simples: não estima para onde vão os eleitores dos candidatos eliminados nem mudanças no comparecimento, e não inclui os votos do exterior.

    Como ler

    Cada estado tem a cor de quem lidera ali a apuração (votos válidos). Abaixo da sigla: % de urnas apuradas e, na linha seguinte, % de Flávio / Lula. Cinza = estado ainda sem urnas apuradas.

    Cada estado tem a cor de quem lidera ali a previsão. A cor fica mais forte conforme as urnas são apuradas: fraca = previsão ainda apoiada no 1º turno; forte = quase toda com votos de hoje. Abaixo da sigla: % de urnas apuradas e, na linha seguinte, a previsão de Flávio / Lula.

    Só os estados com contorno grosso votam para governador hoje. Os demais, claros e listrados, já elegeram o governador no 1º turno (4/10) e estão no mapa apenas como referência.

    Como ler

    Cada estado tem a cor de quem lidera ali a apuração (votos válidos). Abaixo da sigla: % de urnas apuradas e, na linha seguinte, % de Flávio / Lula. Cinza = estado ainda sem urnas apuradas.

    Só os estados com contorno grosso votam para governador hoje. Os demais, claros e listrados, já elegeram o governador no 1º turno (4/10) e estão no mapa apenas como referência.

    Passe o mouse (ou toque) sobre um estado para ver os números.

Espírito Santo — votos por urna

Resultado oficial do 1º turno (04/10/2026) em cada município, zona eleitoral, local de votação e seção. Cada seção é uma urna; as seções ficam em locais de votação (escolas, por exemplo), que pertencem a uma zona eleitoral (a área de um cartório eleitoral). Clique no mapa ou nas tabelas para descer de nível.

O TSE só publica o endereço de cada local de votação, não os limites das zonas. Por isso o município é repartido entre os locais: cada pedaço fica com o local mais próximo, e a cor da área é o resultado das urnas daquele local. As linhas finas separam locais; as grossas, zonas. Os eleitores não votam necessariamente no local mais próximo de casa. Clique numa área ou ponto para abrir o local; clique fora do município ou use "Subir um nível" para voltar.

Como fica a Câmara a partir de 2027, pela apuração

Os 513 deputados federais são eleitos pelo sistema proporcional: cada partido ou federação recebe cadeiras conforme os votos de sua lista no estado. Enquanto a apuração não termina, o TSE distribui as vagas de forma provisória com os votos já contados; elas podem mudar até o fim.
